# RockPaperScissors-WinForms


A retro-inspired Rock-Paper-Scissors game that combines robust C# logic with custom-made pixel art assets. This project demonstrates foundational software engineering principles, UI/UX design, and asynchronous programming.

==> Key Technical Features

- **Asynchronous Game Logic:** Implemented using `async/await` and `Task.Delay` to ensure a smooth, non-blocking user experience during animations and transitions.
- **Dynamic Font & UI Management:** Utilizes a **Recursive** function (`SetFontRecursive`) and `PrivateFontCollection` to dynamically apply custom retro fonts across all UI components from a single source.
- **Custom Visual Assets:** All hand gestures (Rock, Paper, Scissors) and UI buttons were personally designed in **Pixel Art** style to maintain a consistent retro aesthetic.
- **Multimedia Integration:** Features sound effects via `SoundPlayer` and looped background music using `AxWindowsMediaPlayer`.

==> Technologies & Skills

- **Language:** C# (.NET Framework)
- **Architecture:** Event-Driven Programming
- **Algorithms:** Random-based opponent AI logic and score state management.
- **Design:** Pixel Art Asset Creation & Resource Management.
